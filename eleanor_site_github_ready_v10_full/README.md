# Eleanor Reyelt — Website (GitHub-ready)

This folder contains the full site (home, Available with ITTY BITTY, Archive, About with full CV, Contact).

## Deploy on GitHub Pages
1. Create a repo (e.g., `eleanorreyelt.github.io`) and upload all files.
2. If using a different repo name, enable **Settings → Pages** → *Deploy from a branch* → `main` (root).
3. `.nojekyll` is included to serve assets as-is.
4. Replace `assets/resume.pdf` anytime to update the resume link.
